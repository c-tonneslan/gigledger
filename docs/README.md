# docs/

Media for the project README.

- `demo.gif` — 20-30 second screen recording showing the inbox correction flow + Section 179 calculator.
- `screenshot-dashboard.png` — full-width dashboard at 1440px.
- `screenshot-taxes.png` — the Taxes page with the Schedule C preview visible.

To record: Cmd+Shift+5 on macOS, capture the browser window, convert with `ffmpeg -i input.mov -vf "fps=15,scale=1200:-1" demo.gif`.
